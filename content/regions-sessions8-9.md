# 19/vineyards | 狭谷、坡向与密史脱拉风 | 从维埃纳到瓦朗斯，解释西拉如何在成熟边界获得足够热量 | 141–142
罗讷河北部沿维埃纳（Vienne）与瓦朗斯（Valence）之间的河段展开。它只占罗讷河总产量的一小部分，却集中了许多著名的西拉红酒和产量较少的白酒。

## 先读地图
@north-rhone-map
狭窄陡峭的河谷限制了葡萄园面积。右岸多处葡萄园分布在注入罗讷河的横向河谷，河谷和坡地能为园地遮挡寒冷的北风。
## 怎样让西拉成熟
部分园地以花岗岩土壤著称。气候与博若莱相似，属温和大陆性气候，比南罗讷凉爽。密史脱拉风（mistral）沿谷吹下，会降温并损伤葡萄藤。陡峭向阳坡，尤其朝南的坡地，能获得更多日照，帮助西拉在成熟北限附近充分成熟。
坡面和多石土壤往往排水较好，地表石块也能吸收、释放热量。强风吹折枝梢的风险高，但通风能使叶幕和果串更快干燥，减轻真菌病害压力。选址时要同时考虑受光和避风，向阳和背风各自起作用。
陡坡地常给每株藤用一根木桩，或用两根木桩搭成支撑。罗蒂丘的例子用椰纤把枝条绑在桩上。紧凑树形和逐株绑扎帮助抗风。陡坡、窄梯田和手工管理限制机械作业，提高每瓶酒的人工成本。

# 19/grapes | 西拉与三个白葡萄品种 | 从品种、混合发酵与熟化解释红白葡萄酒风格 | 141–142
西拉是北罗讷静止红酒的核心，也是这里课本所列唯一的法定黑葡萄品种。认识白葡萄时，可用维欧尼的芳香，对照玛珊的质地和瑚珊的酸度。

## 西拉如何形成不同风格
西拉颜色深、单宁中等至高，常见黑色水果和黑胡椒，部分酒款呈花香。是否去梗、浸渍多久、怎么管理酒帽，会改变萃取和结构。新小桶可增加木香和熟化成本，旧桶或大桶较少给酒添加强烈木香。
西拉厚皮、色素丰富。温和的北罗讷常见黑胡椒、紫罗兰和较清新的黑果。暖地成熟度更高时，可呈更甜熟的黑果、甘草和甜香料。酸度也受采收成熟度和园地温度影响，品种题可从实际酒款的结构写起。
@north-syrah-flow
部分 cru 传统上允许西拉与指定白葡萄共同发酵，大多数酒款常用纯西拉。这个做法与混种后同时采收有关。共同发酵可影响单宁感并有助于颜色稳定，少量维欧尼还可能增添花香。答题先识别产区允许的白品种，再写可能的风格效果。
共发酵要协调两个品种的成熟时间。若白葡萄已经合适而西拉尚未熟，不能同时获得各自理想的原料。分别采收、发酵和熟化，则能按每批葡萄状态选择工艺，最后判断混合比例。罗蒂丘的白葡萄共发酵和酒庄装瓶前调配不同园地或桶的酒，发生在不同阶段。
发酵前冷浸渍可用于提取颜色及部分香气。带皮发酵时，淋皮可使酒液与酒帽接触，也可在需要时适量引入氧气，管理还原气味。压榨后把自流酒和压榨酒分开评估，结构已足够的批次可只用自流酒。成熟浓郁的西拉有条件融合适量新桶风味，较轻巧的酒可选旧桶或大桶。
## 维欧尼、玛珊、瑚珊
| 品种 | 典型结构与酿造线索 |
| 维欧尼 Viognier | 常见花香和杏子等核果香，酒体饱满，酒精度偏高、酸度偏低，质地可显油润。个别晚采酒接近干型。 |
| 玛珊 Marsanne | 为混合白酒增加酒体和醇厚感。 |
| 瑚珊 Roussanne | 增加酸度与芬芳果味。玛珊和瑚珊混合通常比维欧尼含蓄，陈年可发展榛子香。 |
维欧尼太早采能保留更多酸，但橙花、杏子等香气可能还没充分发展。等到香气明显时，糖分通常已经较高、酸度较低，继续等待可能使酒精感更突出。它的理想采收窗口较窄。孔德里约可用新小桶、旧桶或谨慎接触细酒泥增添质地，桶香与油润感太强会盖住品种香。芳香的年轻酒常较早饮用，玛珊与瑚珊的混合则可从瓶陈中发展榛子香。

# 19/crus | 北罗讷的特级产区 | 罗蒂丘、孔德里约、圣约瑟夫、埃米塔日、克罗兹和科尔纳斯 | 142–144
北罗讷多以独立 cru 名称出售。技术上也可做 Côtes du Rhône。圣约瑟夫和克罗兹–埃米塔日是范围较大的两个产区，尤其适合用园址比较酒款。

## 北段与西岸
| 产区 | 白葡萄与典型风格 |
| 罗蒂丘 Côte Rôtie | 昂皮（Ampuis）周围，最北端，只产红。课本上限为 20% 维欧尼，实际常用纯西拉或只用少量维欧尼。深色、饱满、有香料，精品以清新花香和细致感区别于典型埃米塔日，价位较高。名字有「烘烤的山坡」之意。 |
| 孔德里约 Condrieu、格里叶酒庄 Château-Grillet | 孔德里约只产维欧尼白葡萄酒。近几十年种植面积扩大，课本强调优质酒仍多来自日照充足的陡坡梯田和低产老藤。Château-Grillet 是其间的独立单一酒庄 AOP，也酿维欧尼白酒。 |
| 圣约瑟夫 Saint-Joseph | 西岸由孔德里约延至图尔农，红酒为主，少量玛珊、瑚珊白酒。图尔农梯田的优质红酒在浓度和结构上可接近埃米塔日，靠孔德里约的坡地也有优质酒。肥沃谷底及高原可产较轻、果味和胡椒香明显的红酒，部分用二氧化碳浸渍，常有较好的性价比。 |
罗蒂丘讲义地图在昂皮附近标出 Côte Blonde 和 Côte Brune，两个名字可帮助定位不同坡段，属于同一个罗蒂丘 AOP。
## 埃米塔日及其南北
@hermitage-slope
| 产区 | 园地、酒色与风格 |
| 埃米塔日 Hermitage | 坦恩镇后的朝南陡坡。不同坡度和朝向的具名地块（lieux-dits）同属一个 AOP，传统多地块混合，也有单地块酒。红酒通常是北罗讷最饱满、适合陈年之一，可与最多 15% 玛珊、瑚珊同酿，实践少见。课堂提到山坡上小礼拜堂和隐士的传说。课本白酒约占五分之一，用玛珊、瑚珊。 |
| 克罗兹–埃米塔日 Crozes-Hermitage | 北罗讷产量最大。北边陡坡可产浓郁、复杂、高单宁的酒，较高价的酒也可用橡木桶。南边平原产量较高，常见轻盈果味型。整体声誉一般低于埃米塔日和罗蒂丘。西拉为主，课本允许最多 15% 玛珊和瑚珊用于红酒，也产白酒。 |
| 科尔纳斯 Cornas | 北罗讷最靠南的红酒 cru。较温暖的横向河谷里有避风向阳坡，帮助西拉成熟。只产红，100% 西拉。典型深色、饱满、浓郁、单宁紧实，风格可与埃米塔日比较。 |
埃米塔日的 Les Bessards、Le Méal、Les Greffieux 都是具名地块。坡度、坡向等差异会改变酒体和风格，因此同一个 AOP 既有用不同地块调配的传统，也有只用单一地块原料的酒。课上提到山上小礼拜堂与隐士的传说，用来记 Hermitage 的地名。
地图上的圣佩雷 Saint-Péray 也在北罗讷。用玛珊与瑚珊酿造静止白和起泡白，可和孔德里约的纯维欧尼白酒一起辨认。

# 20/blends | 歌海娜主导的混合酒 | 拆解 GSM、桃红与白葡萄，按目标风格选择酿法 | 145–146
南罗讷常把不同品种、地块或酿法分批发酵后混合。答题可以先写各品种的贡献，再写萃取和熟化如何保持成熟度、酒精度和结构的平衡。

## 黑葡萄品种
| 品种 | 园地与成酒贡献 |
| 歌海娜 Grenache | 南罗讷种植最广，可耐旱、产量潜力较高，需要暖夏成熟。增加酒体、酒精度、红果与香料，单宁相对柔和。炎热年份可出现烤果或果酱味。歌海娜容易氧化，选用新桶时要考虑淡化果味的风险。 |
| 西拉 Syrah | 为混合酒补充颜色与单宁，增加深色果味和香料。南罗讷最热园地可能不利于西拉保持平衡。 |
| 慕合怀特 Mourvèdre | 也称 Mataro 或 Monastrell。生长季需足够热量，南罗讷接近其完全成熟的北限。成熟果可带来深色、高单宁、浓郁黑果、肉味或野味。结构充足的酒有陈年潜力。 |
| 神索 Cinsaut | 耐旱、单宁低、酸度中等，补充芳香和红果，通常对颜色贡献较少。常与歌海娜混合制作清新果味桃红。 |
## 发酵、熟化与酒色
@south-rhone-flow
基础红酒可采用二氧化碳或半二氧化碳浸渍取果味。传统批次可在敞口槽较高温发酵以增加萃取，再用大旧木桶熟化。也可采用发酵前冷浸渍、不锈钢保存，以及适量新桶。酿酒师可混合不同批次，根据成熟度控制单宁和酒精感。
桃红可用直接压榨或短浸皮，接触时间、品种、成熟度与萃取共同影响颜色、酒体及果味。较浓郁的桃红依然需要控制萃取与保持清新。
南部白酒除维欧尼、玛珊、瑚珊，也用克莱雷（Clairette）、白歌海娜（Grenache Blanc）、布布兰克（Bourboulenc）。优质例子可饱满、酒精偏高、酸度低至中、果香较细微，较少用新桶陈年。
## 同一组工序，比较两种红酒
| 环节 | 清新果味、较低成本 | 浓郁、有结构的酒 |
| 原料与取汁前 | 地形适合可机采，筛去缺陷果。用二氧化碳浸渍时要尽量保留完整果串。 | 更细致分拣成熟的葡萄。按果梗成熟度决定去梗、保留部分整串或做发酵前冷浸渍。 |
| 发酵与萃取 | 可控制温度和酒帽操作以保果味，培养酵母有助稳定发酵。通常较早分离皮渣。 | 视原料选择较积极的酒帽管理、较暖发酵或发酵后浸渍，以获得更多颜色和单宁。 |
| 压榨与 MLC | 分取自流酒与压榨酒后按风格试调，红酒通常进行苹果酸–乳酸转化。 | 分段压榨，评估压榨酒是否适合加入。完成苹果酸–乳酸转化后，按酒的结构安排熟化。 |
| 熟化到上市 | 中性容器短熟化可保果味、降低容器和库存成本。视需要混合、澄清稳定并装瓶。 | 大旧桶可保留品种风味，适量新桶可加香料和烘烤风味。把不同品种、地块或工艺批次调配，再完善与装瓶。 |

## 教皇新堡 Châteauneuf-du-Pape
位于东岸，是南罗讷面积最大的 cru，也是法国早期 AOP 制度的重要例子。课堂把名称和 14 世纪阿维尼翁一带的教廷历史相联系。地势总体不陡，坡向的细微变化仍会影响西拉与慕合怀特的成熟。不同土壤、园址和品种让风格差异明显。
课本按传统归类计 13 种葡萄，法国 INAO 按不同颜色变种分别计为 18 个。歌海娜为核心，可有 100% 歌海娜，也有提高慕合怀特比例以突出肉味和野味的酒。优秀红酒能让成熟红果和香料平衡高酒精度；浓度不足的酒款可能显得酒精突出。也产少量白酒。

课本指出法国南部是法国 IGP 产量最大的地区。覆盖原朗格多克–鲁西永多省的 Pays d’Oc 是大范围的地区级标示。较宽的品种选择和单品种酒标，配合充足日照和成熟果味，适合酿造大批量、性价比较高的酒。

## 桃红的颜色与口感

普罗旺斯典型桃红颜色很淡、干型、酒体轻至中，有轻柔红果。浅色可来自整体萃取较低，例如直接压榨或短时间浸皮。塔维勒常有更长的皮汁接触，酒体更饱满、风味更浓，部分可通过瓶陈增加复杂性。红酒从清新果味型到饱满桶陈型均有。优质白酒常见芬芳的候尔或克莱雷。知名普罗旺斯丘桃红常有较高售价，需求、产区声誉和品牌也会影响价格。

## 邦多勒 Bandol
课本提到普罗旺斯沿海有三个小型独立 AOP，重点讲邦多勒。沿海定位时，从马赛往东先找卡西斯（Cassis），再找土伦以西的邦多勒。卡西斯以玛珊与克莱雷混酿的干白闻名。更东的尼斯西北部还有贝莱（Bellet），可酿红、白和桃红。
邦多勒的丘陵像一个朝地中海敞开的半圆。北侧山丘能挡住寒冷的密史脱拉风，朝南坡地得到更多日照，海洋调节夏季高温。当地用干砌石墙修筑梯田（restanques），稳住坡地土壤。典型园地表土浅、石块多，排水良好。
慕合怀特（Mourvèdre）晚熟、厚皮，需要长而温暖的生长季。朝南且避风的梯田有利于果实和单宁成熟。成熟原料为红酒带来深色、饱满酒体和高单宁。年轻时可有深色果味和紧实的单宁，熟化使口感逐渐柔和，瓶陈可发展课本列举的树莓、肉类和甘草香气。
## 邦多勒的三种酒色
| 酒色 | 品种、酿造与风格 |
| 红葡萄酒 | 慕合怀特是核心，歌海娜和神索也属于主要品种。典型酒款浓郁、有结构、适合瓶陈。红酒至少在木桶中熟化 18 个月，常见大木桶（foudre）。 |
| 桃红葡萄酒 | 常见慕合怀特、歌海娜和神索。可用直接压榨、短时浸皮或放血法，颜色也可以很浅。慕合怀特有助于形成较饱满的质地与更明显的单宁，部分酒可瓶陈。桃红是当地实际产量最大的酒色。 |
| 白葡萄酒 | 产量较少，主要品种为克莱雷（Clairette）、布布兰克（Bourboulenc）和白玉霓（Ugni Blanc），典型可有白花和柑橘香。 |
如果题目比较普罗旺斯丘和邦多勒桃红，可以先写两者都能呈浅色，再比较酒体、单宁和陈年潜力。减少果皮色素萃取可以酿出浅色桃红，酒的结构还受品种和酿法影响。
## 邦多勒红酒为什么常有较高售价
葡萄园端，获准的成酒产量上限为每公顷 40 百升，同样面积能做出的酒较少。法规要求手工采收，增加人工投入。按通常的新植规则，当年 7 月 31 日前栽植的地块，最早在栽植当年之后第 7 年才能用于 AOP 红酒，建园投入需更久才能回收。
酒庄端，红酒至少在木桶中熟化 18 个月。桶和酒窖要占用资金与空间，熟化也延后了销售。答题写到「同样面积产酒少」或「酒卖出前需要承担更久的成本」，因果链才完整。
按 2026 年版 AOP 规范，成酒中慕合怀特占红酒的 50%–95%，桃红的 20%–95%。白酒的克莱雷为 30%–95%。用数字答题时写清楚酒色和所指的比例。

## 干旱、树形与六区定位
除西北部外，热和缺水通常是最大的种植挑战。低密度减少相邻葡萄藤对水的竞争，灌木形可为果实遮阴，降低日灼风险。课堂解释了为何种植面积很大，产量排名仍可能较低：干旱与低密度种植会限制单位面积产量。条件与成本允许时，搭架可配合机械采收。潮湿的下海湾则优先处理通风和病害。
讲义的 2025 年数据把西班牙列为葡萄园面积第一、葡萄酒产量第三，约占全球产量 13%，位于意大利和法国之后。OIV 同年初步数据为约 91.9 万公顷和 2,870 万百升。面积与葡萄酒产量是两个指标，旱年还可能进一步减产。

## 红、白里奥哈的酿造风格
红酒常以丹魄带红果和中等单宁，加尔纳恰补酒体和酒精，格拉西亚诺补黑果、酸与单宁，马士罗补颜色、酸和单宁。早饮红可半二氧化碳浸渍来突出红果和柔和口感。桶陈型常先去梗破碎后发酵，用酒帽管理与浸渍控制萃取。可做深色结构型，也可追求较细致的酒。
@rioja-red-flow
传统红里奥哈受波尔多酿造传统影响，常混合多个子区或品种，在美国桶和瓶中长时间熟化，呈香草、柔和口感及更多三类香气。现代浓郁型更重视果实成熟度，可以强化酒帽管理、延长浸渍、相对缩短桶陈，保留黑果和结构，法国或其他欧洲桶可带来较细的辛香，新桶也可带来烘烤味。课上另举单一园或单一品种、部分整串或轻萃取的例子，突出地块和细致果香。
白里奥哈的课本口径是九个获准白品种，以维尤拉 Viura 最常见。维尤拉果香较含蓄，控制产量可提高浓度。传统有意氧化型在美国桶长期熟化，呈深金色，带坚果、蜂蜜和烤果。现代清新型减少接氧以保果香。追求质地的现代酒还可用桶发酵或酒泥熟化，保留新鲜感并增加醇厚度。

## 普里奥拉 Priorat DOQ
从地图上的塔拉戈纳向内陆找普里奥拉。这里夏季漫长、炎热干燥，夜间凉爽。当地的 Llicorella 是含云母的板岩土壤。表层岩片排水快，也能反射和储存太阳热量，帮助晚熟品种成熟。较深的土层可储存部分水分，供葡萄藤在干燥的生长季利用。普里奥拉与邻近的 Montsant 各有自己的产区名称。

## 卢埃达的 50% 怎样读
课本写混合白酒至少 50% 弗德乔。当前产区官方酒款页面写基础静止白的最低 50% 为主要白品种合计，举弗德乔和长相思。复习时区分课本用语与当前官方表述。
弗德乔过去常用于氧化型酒。20 世纪 70 年代起，采用控温和保护性酿造的酒庄开始突出新鲜果味，以 Marqués de Riscal 的尝试为例。卢埃达也有沙地老藤，部分植株早于根瘤蚜时期。集中原料可做酒泥熟化或桶发酵的丰满型白酒。
