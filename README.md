# WSET Ⅲ 通关指南

个人葡萄酒学习站点。第 4–10 章按课本顺序编排，共46个阅读单元。第7–10章已依据本批课本、讲义与课堂转写整合正文和图示；原音频及练习册第5、6页原题仍待提供。

## 内容结构

- 第 4 章「葡萄藤」：结构、葡萄种与品种、繁殖、根瘤蚜与嫁接，另附讲义品种表。
- 第 5 章「生长环境」：生长条件、热量、阳光、水分、气候、土壤与养分。
- 第 6 章「葡萄园管理」：选址栽种、年周期、整枝修剪、冠层、密度、产量、管理实例、病虫害、栽培方式和采收。

第 4–6 章共 22 个既有阅读单元。各单元以一个具体问题开篇，在首次使用处解释芽、新梢、木质化、冠层、结果力、潜在酒精度等术语；密度、留芽量与产量配有换算例。完整年周期和木龄各有固定位置；正文不再按 Session 1、2 重复编排。

`#chapter/4`、`#chapter/5`、`#chapter/6` 为章目录；`#read/章节/单元` 为正文。`#review/4`、`#review/5`、`#review/6` 列出逐章课本与讲义去向、配图检查及未确认的转写片段。历史阅读链接会解析到相应新章节。搜索只索引新正文。自测的回看链接直接到对应段落，练习册保留原题与原保存键，并提供填写范围提示。

`#practice` 保留原课程练习身份：两课各 8 道自编选择题；练习册含 8 道原题，第一课另有 16 个白葡萄、10 个红葡萄填写表。原机构答案尚未提供，自查提示不是官方评分细则。

## 图示

首页保留已认可的葡萄园封面，章节卡片、章目录与知识地图使用配套期刊插画。教学图在保留结构、步骤、标注和图注的同时，加入葡萄叶插画、果串层次、芽鳞、卷须、木纹及细腻纸面与土层。装饰插画与教学示意分别承担视觉叙事和知识解释，不互相替代。

`dist/study-diagrams.js` 绘制有明确课本／讲义依据的 SVG 教学图。整枝与修剪分别比较课本图 6.3 的三种冬季／夏季结构，Sylvoz 按讲义单列。标明多年生木、一年生木和当年新梢；另绘短枝／长枝更新步骤、单／双居由、冠层操作、摘青、春霜机制和受害路径。每张图下方单独解释概念，桌面并排、窄屏竖排。此前混合了采收等无关内容的拼图已从阅读正文与知识地图撤下。

已对照课本22幅编号配图与37页讲义，补入16组图示，重画年周期与贵腐两组，共51组教学图。新增成熟曲线、分类层级、克隆选择、反射光路、梯田、海风与海拔、气候模式和法国定位、坐果问题、两种葡萄园管理实例、病害外观、害虫类别、管理分工、资源负载及酷热野火路径。课本原图的跳转指向对应知识图，重复照片不重复放置。

图用于说明结构和机制；省略的芽梢、比例、示意曲线等均有图注。原始课本照片、讲义和完整课堂转写不公开上传。

## 学习记录

笔记、练习册答案、阅读进度及知识地图自查保存在当前浏览器，不跨设备同步。原 Session 阅读进度保留；新章节另存阅读进度，不把旧课程已读直接认定为新章节已读。旧笔记显示在对应新单元下方，原答案键不变。

## 预览与部署

原生 HTML、CSS、JavaScript。可用静态服务器预览 `dist/`。Cloudflare Workers Static Assets 从 `./dist` 部署，GitHub main 更新触发构建。

维护内容后运行：

```sh
python3 scripts/build-viticulture.py
python3 scripts/build-winemaking.py
python3 scripts/build-logic-review.py
python3 scripts/build-learner-support.py
```

第4–6章的现行内容源为 `content/viticulture.json`，包含既有正文、旧链接和迁移映射；`dist/book-data.js` 是生成物。早期 restructure、beginner_revision 和 editorial 迁移脚本只作历史记录，不再覆盖现行内容。第7–10章仍维护 `content/winemaking.json`。图注等渲染逻辑在对应的 `dist/book.js`、`dist/study-diagrams.js`、`dist/winemaking-diagrams.js` 中维护。

`content/logic-review.json` 记录2026-10-27本轮46单元的学习结论与20单元修订去向，`scripts/logic-review.js` 是核对页模板。它们生成 `dist/logic-review.js`，在各章核对页显示；结论清单不替代正文前提，也不构成无遗漏保证。原题、保存键和既有图视频保留。

本站为个人学习整理，非 WSET 官方网站。课本范围为用户已提供 p.30–102；课堂按已提供转写核对，未核听原音频，转写中的不清片段保留于资料索引。

正文包括工艺机制、适用条件、数值范围、实例与例外，配有15组课本编号图解及讲义趋势图。新章支持正文搜索、具体段落跳转、笔记保存和阅读标记。首页封面及章节插画保持统一期刊风格；阅读标记不等于掌握自查。

## 新学习者路径与自查

`#start` 说明第4–10章的阅读顺序、六组基础术语、学习记录的含义及资料边界。首页提供入口。原练习册第5、6页、机构评分细则和待辨原音频仍待提供；产区、起泡／加强酒及系统品鉴专章不在本批资料范围内。

`content/learner-support.json` 维护第7–10章12个自编自查主题（每题解释、比较、应用三项）和2个四步情境；`scripts/learner-support.js` 维护导读模板，运行 `scripts/build-learner-support.py` 生成 `dist/learner-support.js`。知识地图共有24个主题、5个情境。原12个主题、3个情境和保存键保留；已读、小测证据和自评状态分开。无关联小测的主题不会显示虚构的自测链接。

阅读末尾与练习页可进入 `#map/chapter/4` 至 `#map/chapter/10`，直接筛选本章并定位主题区。自编自查不代替机构原练习册，不自动评分。氧气单元首次使用香气分类处补入定义，并在导读注明WSET词汇表依据。
